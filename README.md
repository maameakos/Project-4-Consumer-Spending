OVERVIEW
This project is dedicated to analyzing consumer spending patterns by leveraging the power of Pandas for data manipulation, Tableau for data visualization, and machine learning for predictive analytics. The primary objective is to uncover trends in consumer behavior, predict future spending, and identify critical factors influencing purchasing decisions. This focus on customer behavior is particularly relevant to our finance and data analysis.
 
OBJECTIVES
Our team used a public dataset from Kaggle to analyze the data. The CSV file contains customer data with various attributes related to demographics, income, spending habits, and purchase behavior. Each row in the file represents a different customer, while the columns represent different features. Thanks to Aditya Goyal (Owner) and Kaggle for providing the dataset.
 
Our team chose Pandas and Tableau for this project as the technologies, in addition of machine learning to predict that the United States consumer spending will exceed that of other countries worldwide.
 
We begins by cleaning, transforming, and preparing the dataset for analysis using Pandas, followed by creating interactive visualizations in Tableau to uncover insights.
Implementing machine learning models to predict consumer spending trends using algorithms such as linear regression, decision trees, and random forests are implemented and evaluated. The goal is to identify the most effective model for predicting future spending based on historical data.
We are building comprehensive dashboards in Tableau to visually represent consumer spending patterns and the outcomes of the machine learning models.

The data was obtained from Kaggle https://www.kaggle.com.
